tvchart · TradingView-style charts, in Python

A tested library and CLI that turns yfinance + pandas + Plotly into a three-panel technical chart, a JSON summary, and a multi-timeframe bias score. Indicators follow TradingView's own conventions.

pip install git+https://github.com/LoloMojo/Python-stock-charting.git
tvchart AAPL -i 1d -p 1y --plan long --mtf -o aapl.html

Live-generated AAPL daily chart. Scroll to zoom, drag to pan, use the toolbar for trendlines and rectangles.

Limits

yfinance is an unofficial, delayed feed. No Pine Script, no saved drawings, no server-side alerts. Research tool, not an execution system.
